Pendahuluan (Introduction)

Terima kasih telah menggunakan aplikasi SaldoKu: Cek Saldo e-Money NFC ("Aplikasi"), yang dikembangkan oleh ndesodev. Dokumen Kebijakan Privasi ini menerangkan bagaimana informasi ditangani, digunakan, dan dilindungi saat Anda mengoperasikan Aplikasi.

Kami memiliki komitmen penuh dalam melindungi privasi Anda. Aplikasi ini didesain secara arsitektural untuk bekerja dengan prinsip offline-first, sehingga kami tidak menyelenggarakan server penyimpanan eksternal untuk menyimpan data kartu pengguna.

Dengan mengunduh, memasang, atau menggunakan Aplikasi ini, Anda menyatakan telah membaca, memahami, dan menyetujui ketentuan pemrosesan informasi sesuai Kebijakan Privasi ini.

2

Pengumpulan & Penggunaan Data

A. Data Kartu NFC (100% On-Device Processing)

  • • Informasi Kartu: Aplikasi membaca saldo e-money, nomor kartu, dan riwayat transaksi (log) langsung dari chip kartu prabayar Anda melalui sensor hardware Near Field Communication (NFC) yang ada pada smartphone Anda.
  • • 100% Pemrosesan Lokal: Seluruh parsing protokol kartu dan kalkulasi saldo diproses secara instan di dalam memori lokal ponsel Anda. Data sensitif ini TIDAK PERNAH dikirim, diunggah, disalin, atau disimpan di server cloud eksternal mana pun milik pengembang ataupun pihak ketiga.

B. Penyimpanan Lokal (DataStore & Cadangan JSON)

  • • Riwayat Pindai & Preferensi: Riwayat pemindaian dan pengaturan personal Anda tersimpan di penyimpanan internal yang terisolasi dan terenkripsi oleh sistem operasi Android melalui mekanisme Android DataStore / Room Database.
  • • Fitur Backup Mandiri: SaldoKu menyediakan opsi bagi Anda untuk mencadangkan (ekspor) histori secara manual ke file JSON atau file dokumen PDF lokal. File ini berada di bawah kendali penuh pengguna di folder penyimpanan yang dipilih.

C. Koneksi Bluetooth (Thermal Printer)

Aplikasi meminta izin Bluetooth semata-mata untuk memindai dan menghubungkan perangkat dengan printer thermal Bluetooth guna mencetak struk fisik bukti cek saldo/transaksi. Data identitas perangkat Bluetooth tidak pernah dicatat atau dilacak di luar keperluan pencetakan struk ini.

Izin Perangkat (Device Permissions)

SaldoKu hanya meminta izin yang mutlak diperlukan untuk mengoperasikan fungsi-fungsi aplikasi berikut:

android.permission.NFC Fitur Utama

Akses Hardware NFC

Digunakan untuk mendeteksi kartu dan membaca saldo e-money seketika kartu ditempelkan di belakang ponsel.

BLUETOOTH_CONNECT BLUETOOTH_SCAN

Akses Bluetooth Printer

Menemukan dan mentransmisikan format cetak struk fisik ke printer thermal mini portabel.

android.permission.INTERNET

Akses Jaringan Internet

Semata-mata dimanfaatkan oleh pustaka Google AdMob untuk memuat materi iklan dan verifikasi konektivitas.

Storage / File Picker Access

Akses Penyimpanan Berkas

Diperlukan saat Anda memilih untuk mengekspor dokumen laporan (PDF) atau memulihkan cadangan berkas JSON secara mandiri.

Keamanan Data (Data Security)

Kepercayaan Anda adalah prioritas kami. Karena seluruh data finansial, nomor kartu, dan nominal saldo dioperasikan sepenuhnya di dalam lingkungan terisolasi (sandbox) perangkat lokal:

Nol Risiko Kebocoran di Server Tidak ada database server pihak pengembang yang menyimpan data kartu Anda, sehingga kemungkinan terjadi kebocoran basis data berskala server adalah nihil.

* Kami menyarankan Anda tetap menjaga keamanan fisik perangkat (seperti menggunakan kunci layar PIN, Pola, atau Biometrik) agar riwayat transaksi lokal tidak dilihat oleh orang yang tidak berhak.
